# Handoff 模板

本项目提供两种 Handoff 模板，根据变更复杂度选择：

| 模板 | 文件 | 适用场景 |
|------|------|---------|
| **单轮 Handoff** | [handoff-single-round-template.md](./handoff-single-round-template.md) | 单轮变更：Bug 修复、单次组件改动、基础设施调整 |
| **多轮 Handoff** | [handoff-multi-round-template.md](./handoff-multi-round-template.md) | 多轮原子事务：递进式功能迭代、多阶段架构重构 |

规则详情见 `.kimi-code/rules/project_rules.md` → ADD-8 → 目录路径与文件命名约定。
